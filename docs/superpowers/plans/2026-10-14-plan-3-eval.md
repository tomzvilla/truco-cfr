# Plan 3 — Torneo (con Claude Haiku de rival), faroleo y manos destacadas

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Medir al bot entrenado contra el azar, el heurístico propio y Claude Haiku, medir cuánto farolea y encontrar manos de farol para mostrar; todo sale en `eval/results/*.json` para que la web lo muestre.

**Architecture:** Un crate Rust nuevo, `eval/` (`truco-eval`), que usa el motor tal cual y tiene un binario de línea de comandos con tres subcomandos (`tournament`, `bluff`, `highlights`). Claude Haiku juega a través de Claude Code en modo no interactivo (`claude -p`), con la suscripción del usuario: cada decisión es una llamada con la situación descripta en castellano y las jugadas legales numeradas. Los torneos largos se pueden cortar y retomar sin rejugar nada.

**Tech Stack:** Rust 1.99 (edición 2021), `serde` + `serde_json`, `rand 0.8`; Claude Code 2.1 (`claude.exe` de Windows, llamado desde WSL) con el modelo `haiku`.

**Spec:** `docs/superpowers/specs/2026-10-13-truco-cfr-design.md` (secciones 1 —criterios de éxito 3 y 5—, 3.3 y 4).

## En criollo: qué hace este plan

Hasta ahora sabemos que el bot le gana al heurístico el 60 %, pero ese número salió del propio entrenamiento. Este plan arma la **evidencia** para el post:

1. **El torneo**: partidos completos a 30 con el "formato duplicado" (cada reparto se juega dos veces cambiando de asiento, así la suerte de las cartas se compensa). 2000 partidos contra el azar y contra el heurístico. Sale el porcentaje de partidos ganados con su margen de error y los puntos promedio por mano.
2. **Claude Haiku de rival**: una IA de lenguaje de Anthropic jugando al truco. En cada jugada le describimos la situación en castellano ("tus cartas: 1 de espada…; el rival cantó truco…") con las jugadas posibles numeradas, y contesta un número. Nunca ve las cartas escondidas del bot. Como cada jugada tarda unos 5 segundos, se juegan 100 partidos (no 2000).
3. **El faroleo**: le preguntamos a la red, en miles de situaciones, con qué probabilidad canta envido según sus tantos, y cuántos de sus truco salen de manos flojas. Es el "aprendió a mentir".
4. **Manos destacadas**: buscamos en los registros del torneo manos donde el bot faroleó y el rival (el heurístico o Haiku) se achicó, para mostrarlas como repeticiones en la web.

## Decisiones tomadas al planificar (desvíos y precisiones respecto del spec)

1. **Sin rivales de terceros ni comparación de reglas con marianogappa** (lo pidió el usuario: "no uses bots de otra gente, porque no están muy desarrollados"). Se van el heurístico de nicovon24 (su repo ya no tiene código, además) y el bot de marianogappa. También se va la comparación de reglas contra su motor (spec, criterio 1 y sección 4), que necesitaba ese motor: las reglas propias quedan cubiertas por los 105 tests del motor. Queda escrito en las limitaciones del informe.
2. **El torneo y los análisis van en Rust, no en Python.** El spec ubica `eval/` sin fijar lenguaje. En Rust están todos los agentes, el `MlpAgent` (la misma política que usará la web) y los registros de cada mano (`HandRecord`), y no hace falta recompilar el puente de PyO3.
3. **Claude Haiku entra en este plan** (el spec lo dejaba para la v2; lo pidió el usuario). Una llamada por decisión, sin memoria entre llamadas: cada pedido describe todo lo que el jugador ve (cartas propias, bazas, cantos, tantos mostrados, puntaje) y numera las jugadas legales. Respuesta = el primer número del texto. Si no hay número válido o la llamada falla (error, límite de uso, más de 120 s), se reintenta una vez y después se juega la jugada prudente (no querer, o tirar la carta más baja) y se cuenta como **fallback**. Medición del 2026-10-14: ~5 s por llamada, ~840 tokens de entrada y ~430 de salida (razonamiento incluido), US$ 0,0004 a precio de lista (con la suscripción no se cobra; consume cupo de uso). Por eso **100 partidos** contra Haiku, con 4 llamadas en paralelo: ~4500 llamadas, alrededor de 1,5 h. Si el piloto (Task 2) da otro ritmo, se ajusta la cantidad de pares y se anota.
4. **Torneos que se retoman.** El registro de cada rival (`eval/logs/<rival>.jsonl`) se escribe par por par. Con `--resume true`, una corrida cortada (por ejemplo, por la protección de memoria de Claude Code) sigue desde los pares completos; una línea a medias o un par incompleto se descartan. Sin `--resume`, el registro se borra y se empieza de cero.
5. **Fuerza de una mano para el truco** (spec 3.3): probabilidad de ganar las bazas contra una mano al azar si los dos juegan las cartas con la regla del heurístico y nadie canta. Se precalcula para las 9880 manos posibles y los dos roles (mano y pie) con 300 simulaciones cada una, y se expresa como **percentil** entre todas las manos. "Mano floja" = percentil < 0,30. Se mide sobre las tres cartas repartidas, no en el momento del canto; queda escrito como limitación.
6. **Situaciones del análisis de faroleo**: se juegan 20 000 manos del bot contra sí mismo (puntaje inicial con la misma distribución del entrenamiento, `sample_scores`) y se consulta la red en cada situación que aparece. "Primera oportunidad de envido" = la primera decisión de ese jugador en la mano con `Envido` legal y sin ningún canto de envido previo. Se reportan las dos cosas: la **probabilidad** promedio que da la red (siempre mayor que cero, porque es un softmax) y la **frecuencia real** de cantos muestreados, que es la que tiene sentido para el criterio 5.
7. **Un archivo por rival** (`eval/results/tournament-<rival>.json`) en lugar de un `tournament.json` único, para poder correr un rival sin pisar los otros.
8. **Haiku no es reproducible** (el modelo muestrea sus respuestas): el resultado contra Haiku se informa como una corrida, con su intervalo, y la fecha y el modelo exacto (`rivalModel`, tomado de la respuesta de Claude Code).

/// La regla de cartas del heurístico: con la carta del rival en la mesa, la más baja que la gana
/// (o la más baja si ninguna gana); abriendo la primera baza, la más baja; abriendo otra, la más alta.
/// La usan el heurístico y la medida de fuerza de una mano de `truco-eval`.
pub fn heuristic_card(o: &Observation) -> Action {
    // Slots sin jugar, de la carta más fuerte a la más débil.
    let unplayed: Vec<usize> = (0..3).filter(|&s| o.legal & bit(JUGAR0 + s) != 0).collect();
    let weakest = *unplayed.last().expect("sin cartas para jugar");
    if let Some(opp) = o.opp_played[o.baza] {
        return match unplayed
            .iter()
            .rev()
            .find(|&&s| o.hand[s].rank() > opp.rank())
        {
            Some(&s) => JUGAR0 + s,
            None => JUGAR0 + weakest,
        };
    }
    if o.baza == 0 {
        JUGAR0 + weakest
    } else {
        JUGAR0 + unplayed[0]
    }
}
```

//! Intervalos de confianza: Wilson para porcentajes y bootstrap para promedios.
use rand::rngs::SmallRng;
use rand::{Rng, SeedableRng};

/// Intervalo de Wilson al 95 % para `wins` éxitos en `n` intentos.
pub fn wilson(wins: u64, n: u64) -> (f64, f64) {
    if n == 0 {
        return (0.0, 1.0);
    }
    let z = 1.96;
    let nf = n as f64;
    let p = wins as f64 / nf;
    let denom = 1.0 + z * z / nf;
    let center = (p + z * z / (2.0 * nf)) / denom;
    let half = z * (p * (1.0 - p) / nf + z * z / (4.0 * nf * nf)).sqrt() / denom;
    ((center - half).max(0.0), (center + half).min(1.0))
}

/// Media de `suma / cantidad` y su intervalo al 95 % por bootstrap de percentiles.
/// Cada elemento es un grupo que se remuestrea entero (por ejemplo, los puntos netos y la cantidad
/// de manos de un par duplicado), así la correlación dentro del grupo no achica el intervalo.
pub fn bootstrap_mean(clusters: &[(f64, u64)], resamples: usize, seed: u64) -> (f64, f64, f64) {
    let total: f64 = clusters.iter().map(|c| c.0).sum();
    let count: u64 = clusters.iter().map(|c| c.1).sum();
    if count == 0 {
        return (0.0, 0.0, 0.0);
    }
    let mean = total / count as f64;
    let mut rng = SmallRng::seed_from_u64(seed);
    let mut means = Vec::with_capacity(resamples);
    for _ in 0..resamples {
        let (mut s, mut c) = (0.0, 0u64);
        for _ in 0..clusters.len() {
            let k = rng.gen_range(0..clusters.len());
            s += clusters[k].0;
            c += clusters[k].1;
        }
        if c > 0 {
            means.push(s / c as f64);
        }
    }
    means.sort_by(|a, b| a.partial_cmp(b).expect("media no numérica"));
    let q = |f: f64| means[(f * (means.len() - 1) as f64).round() as usize];
    (mean, q(0.025), q(0.975))
}
```

//! Argumentos `--clave valor` de la línea de comandos (sin dependencias).
use std::collections::HashMap;
use std::path::PathBuf;
use std::str::FromStr;

pub struct Args {
    values: HashMap<String, String>,
}

impl Args {
    pub fn parse(argv: &[String]) -> Result<Args, String> {
        let mut values = HashMap::new();
        let mut it = argv.iter();
        while let Some(key) = it.next() {
            let name = key
                .strip_prefix("--")
                .ok_or_else(|| format!("argumento inesperado: {key} (se esperaba --clave valor)"))?;
            let value = it.next().ok_or_else(|| format!("falta el valor de --{name}"))?;
            values.insert(name.to_string(), value.clone());
        }
        Ok(Args { values })
    }

    pub fn get<T: FromStr>(&self, key: &str, default: Option<T>) -> Result<T, String> {
        match self.values.get(key) {
            Some(v) => v
                .parse()
                .map_err(|_| format!("valor inválido para --{key}: {v}")),
            None => default.ok_or_else(|| format!("falta --{key}")),
        }
    }

    pub fn path(&self, key: &str, default: &str) -> PathBuf {
        PathBuf::from(self.values.get(key).map(String::as_str).unwrap_or(default))
    }
}

### Task 1: Torneo contra el azar y el heurístico (retomable)

**En criollo:** el corazón de la evaluación. Para cada rival se juegan pares de partidos repartidos entre varios hilos de la CPU. Cada par usa el mismo reparto dos veces cambiando de asiento. Se guarda cuántos ganó el bot (con su margen de Wilson), cuántos puntos saca por mano en promedio (con su margen por bootstrap) y el registro completo de cada mano, que después usan las manos destacadas. El registro se escribe par por par: si la corrida se corta, se retoma desde donde quedó.

/// Una mano: cartas como "1E", acciones como (asiento, nombre de ACTION_NAMES).
#[derive(Serialize, Deserialize, Clone, Debug, PartialEq)]
#[serde(rename_all = "camelCase")]
pub struct HandLog {
    pub mano: usize,
    pub start_scores: [u8; 2],
    pub hands: [[String; 3]; 2],
    pub actions: Vec<(usize, String)>,
    pub points: [u8; 2],
}

impl HandLog {
    pub fn from_record(r: &HandRecord) -> HandLog {
        HandLog {
            mano: r.mano,
            start_scores: r.start_scores,
            hands: r.hands.map(|h| h.map(|c| c.to_string())),
            actions: r
                .actions
                .iter()
                .map(|&(p, a)| (p, ACTION_NAMES[a].to_string()))
                .collect(),
            points: r.points,
        }
    }

    pub fn cards(&self, seat: usize) -> [Card; 3] {
        self.hands[seat]
            .clone()
            .map(|s| Card::parse(&s).unwrap_or_else(|| panic!("carta inválida en el registro: {s}")))
    }

    pub fn action_ids(&self) -> Vec<(usize, Action)> {
        self.actions
            .iter()
            .map(|(p, name)| {
                let a = ACTION_NAMES
                    .iter()
                    .position(|n| n == name)
                    .unwrap_or_else(|| panic!("acción desconocida en el registro: {name}"));
                (*p, a)
            })
            .collect()
    }
}

pub fn write_logs(path: &Path, logs: &[MatchLog]) -> Result<(), String> {
    if let Some(dir) = path.parent() {
        std::fs::create_dir_all(dir).map_err(|e| format!("no pude crear {}: {e}", dir.display()))?;
    }
    let f = std::fs::File::create(path).map_err(|e| format!("no pude escribir {}: {e}", path.display()))?;

        serde_json::to_writer(&mut w, m).map_err(|e| e.to_string())?;
        w.write_all(b"\n").map_err(|e| e.to_string())?;
    }
    w.flush().map_err(|e| e.to_string())
}

/// Pares completos que ya están en `path`. Una línea ilegible (cortada a la mitad) o un par al que
/// le falta uno de sus dos partidos se descartan.
fn load_done(path: &Path, pairs: u64) -> BTreeMap<u64, Vec<MatchLog>> {
    let mut done: BTreeMap<u64, Vec<MatchLog>> = BTreeMap::new();
    if let Ok(text) = std::fs::read_to_string(path) {
        for line in text.lines() {
            if let Ok(m) = serde_json::from_str::<MatchLog>(line) {
                if m.pair < pairs {
                    done.entry(m.pair).or_default().push(m);
                }
            }
        }
    }
    done.retain(|_, v| {
        v.sort_by_key(|m| m.bot_seat);
        v.len() == 2 && v[0].bot_seat == 0 && v[1].bot_seat == 1
    });
    done
}

/// Puntos netos del bot y cantidad de manos de un partido.
fn net_points(m: &MatchLog) -> (f64, u64) {
    let b = m.bot_seat;
    let net: i64 = m.hands.iter().map(|h| h.points[b] as i64 - h.points[1 - b] as i64).sum();
    (net as f64, m.hands.len() as u64)
}

fn append(sink: &Mutex<BufWriter<std::fs::File>>, logs: &[MatchLog]) -> Result<(), String> {
    let mut w = sink.lock().expect("registro envenenado");
    for m in logs {
        serde_json::to_writer(&mut *w, m).map_err(|e| e.to_string())?;
        w.write_all(b"\n").map_err(|e| e.to_string())?;
    }
    w.flush().map_err(|e| e.to_string())
}

pub fn run_rival(
    net: Arc<Mlp>,
    model_label: &str,
    rival: &str,
    opts: &RivalOptions,
    cfg: &TournamentConfig,
    logs_path: &Path,
) -> Result<(RivalReport, Vec<MatchLog>), String> {
    let mut all = load_done(logs_path, cfg.pairs);
    let resumed = all.len() as u64;
    // Se reescribe limpio (sin líneas cortadas ni pares incompletos) y se sigue agregando.
    write_logs(logs_path, &all.values().flatten().cloned().collect::<Vec<_>>())?;
    let file = OpenOptions::new()
        .append(true)
        .open(logs_path)
        .map_err(|e| format!("no pude abrir {}: {e}", logs_path.display()))?;
    let sink = Mutex::new(BufWriter::new(file));
    let todo: Vec<u64> = (0..cfg.pairs).filter(|i| !all.contains_key(i)).collect();
    let counters = Arc::new(Counters::default());
    let threads = cfg.threads.clamp(1, todo.len().max(1));
    let per_worker: Vec<Result<Vec<(u64, Vec<MatchLog>)>, String>> = std::thread::scope(|s| {
        let handles: Vec<_> = (0..threads)
            .map(|w| {
                let net = net.clone();
                let counters = counters.clone();
                let (todo, sink) = (&todo, &sink);
                s.spawn(move || -> Result<Vec<(u64, Vec<MatchLog>)>, String> {
                    let mut rival_agent = make_rival(rival, opts, counters)?;
                    let mut out = Vec::new();
                    for &i in todo.iter().skip(w).step_by(threads) {
                        // Las mismas semillas que la evaluación del entrenamiento (engine-py).
                        let mut rng =
                            SmallRng::seed_from_u64(cfg.seed ^ i.wrapping_mul(0xD1B5_4A32_D192_ED03));
                        let deal_seed = cfg.seed.wrapping_mul(31).wrapping_add(i);
                        let mut bot = MlpAgent::shared(net.clone(), PolicyKind::Strategy, "bot");
                        let d = play_duplicate(&mut bot, &mut *rival_agent, deal_seed, &mut rng);
                        let logs = vec![
                            MatchLog::from_result(i, 0, &d.a_as_seat0),
                            MatchLog::from_result(i, 1, &d.a_as_seat1),
                        ];
                        append(sink, &logs)?;
                        out.push((i, logs));
                    }
                    Ok(out)
                })
            })
            .collect();
        handles
            .into_iter()
            .map(|h| h.join().expect("un hilo del torneo entró en pánico"))
            .collect()
    });
    for r in per_worker {
        all.extend(r?);
    }

    let mut wins = 0u64;
    let mut clusters = Vec::with_capacity(all.len());
    for ms in all.values() {
        wins += ms.iter().filter(|m| m.winner == m.bot_seat).count() as u64;
        let (net, hands) = ms.iter().map(net_points).fold((0.0, 0), |a, b| (a.0 + b.0, a.1 + b.1));
        clusters.push((net, hands));
    }
    let logs: Vec<MatchLog> = all.into_values().flatten().collect();
    let games = logs.len() as u64;
    let (lo, hi) = wilson(wins, games);
    let (pph, plo, phi) = bootstrap_mean(&clusters, 2000, cfg.seed);
    let report = RivalReport {
        rival: rival.to_string(),
        model: model_label.to_string(),
        pairs: cfg.pairs,
        games,
        wins,
        win_rate: if games == 0 { 0.0 } else { wins as f64 / games as f64 },
        wilson95: [lo, hi],
        hands: clusters.iter().map(|c| c.1).sum(),
        points_per_hand: pph,
        points_per_hand_ci95: [plo, phi],
        resumed_pairs: resumed,
        rival_decisions: counters.decisions.load(Ordering::Relaxed),
        fallbacks: counters.fallbacks.load(Ordering::Relaxed),
        rival_cost_usd: counters.cost_micro_usd.load(Ordering::Relaxed) as f64 / 1e6,
        rival_model: counters.model.lock().expect("modelo").clone(),
        seed: cfg.seed,
        threads,
    };
    Ok((report, logs))
}

//! Claude Haiku como rival. Cada decisión es una llamada a Claude Code en modo no interactivo
//! (`claude -p`) con la suscripción del usuario: sin API key, sin herramientas, sin MCP y sin la
//! configuración del usuario, con un prompt de sistema propio. No guarda memoria entre llamadas:
//! cada pedido describe todo lo que ve el jugador.

pub fn card_name(c: Card) -> String {
    let suit = match c.suit() {
        Suit::Espada => "espada",
        Suit::Basto => "basto",
        Suit::Oro => "oro",
        Suit::Copa => "copa",
    };
    format!("{} de {suit}", c.number())
}

fn level_name(level: u8) -> &'static str {
    match level {
        2 => "truco",
        3 => "retruco",
        _ => "vale cuatro",
    }
}

pub fn action_label(a: Action, obs: &Observation) -> String {
    let envido = obs.envido_status == EnvidoStatus::Pending;
    let pending = obs.truco_pending.is_some();
    match a {
        JUGAR0 | JUGAR1 | JUGAR2 => format!("jugar el {}", card_name(obs.hand[a - JUGAR0])),
        ENVIDO => "cantar envido".into(),
        REAL_ENVIDO => "cantar real envido".into(),
        FALTA_ENVIDO => "cantar falta envido".into(),
        TRUCO => "cantar truco".into(),
        RETRUCO if pending => "quiero retruco (aceptar el truco y subir)".into(),
        RETRUCO => "cantar retruco".into(),
        VALE_CUATRO if pending => "quiero vale cuatro (aceptar el retruco y subir)".into(),
        VALE_CUATRO => "cantar vale cuatro".into(),
        QUIERO if envido => "quiero (el envido)".into(),
        QUIERO => "quiero (el truco)".into(),
        NO_QUIERO if envido => "no quiero (el envido)".into(),
        NO_QUIERO => "no quiero (el truco)".into(),
        MAZO => "irse al mazo".into(),
        _ => unreachable!("acción fuera de rango: {a}"),
    }
}

fn who(mine: bool) -> &'static str {
    if mine {
        "vos"
    } else {
        "el rival"
    }
}

/// La situación tal como la ve el jugador, en castellano.
pub fn describe(obs: &Observation) -> String {
    let mut s = String::new();
    s += &format!("Puntaje: vos {}, el rival {} (se juega a 30).\n", obs.my_score, obs.opp_score);
    s += if obs.is_mano {
        "En esta mano sos mano (jugás primero).\n"
    } else {
        "En esta mano sos pie (el rival es mano).\n"
    };
    let cards: Vec<String> = (0..3)
        .map(|i| {
            let played = obs.my_played.contains(&Some(i));
            format!("{}{}", card_name(obs.hand[i]), if played { " (ya la jugaste)" } else { "" })
        })
        .collect();
    s += &format!("Tus cartas: {}.\n", cards.join(", "));
    s += &format!("Tus tantos de envido: {}.\n", obs.my_tantos);
    for b in 0..=obs.baza.min(2) {
        let mine = obs.my_played[b].map(|i| card_name(obs.hand[i]));
        let theirs = obs.opp_played[b].map(card_name);
        if mine.is_none() && theirs.is_none() {
            continue;
        }
        let result = match obs.baza_results[b] {
            Some(RelResult::Mine) => " → la ganaste vos",
            Some(RelResult::Theirs) => " → la ganó el rival",
            Some(RelResult::Parda) => " → parda",
            None => "",
        };
        s += &format!(
            "Baza {}: vos {}, el rival {}{result}.\n",
            b + 1,
            mine.unwrap_or_else(|| "todavía no jugaste".into()),
            theirs.unwrap_or_else(|| "todavía no jugó".into())
        );
    }
    let calls: Vec<String> = obs
        .envido_calls
        .iter()
        .flatten()
        .map(|&(k, mine)| {
            let name = match k {
                EnvidoKind::Envido => "envido",
                EnvidoKind::Real => "real envido",
                EnvidoKind::Falta => "falta envido",
            };
            format!("{name} ({})", who(mine))
        })
        .collect();
    s += &match obs.envido_status {
        EnvidoStatus::NotPlayed => "Envido: no se cantó.\n".to_string(),
        EnvidoStatus::Pending => format!("Envido: se cantó {}; falta la respuesta.\n", calls.join(", ")),
        EnvidoStatus::Accepted => format!("Envido: se cantó {} y se quiso.\n", calls.join(", ")),
        EnvidoStatus::Declined => format!("Envido: se cantó {} y no se quiso.\n", calls.join(", ")),
    };
    if let Some(t) = obs.opp_revealed_tantos {
        s += &format!("El rival mostró {t} de tantos.\n");
    }
    s += &match obs.truco_pending {
        Some((level, mine)) => format!("Truco: {} cantó {}; falta la respuesta.\n", who(mine), level_name(level)),
        None if obs.truco_level == 1 => "Truco: no se cantó (la mano vale 1).\n".to_string(),
        None => format!(
            "Truco: se quiso el {} (la mano vale {}).\n",
            level_name(obs.truco_level),
            obs.truco_level
        ),
    };
    s
}

/// El pedido completo y las acciones en el orden del menú.
pub fn prompt(obs: &Observation) -> (String, Vec<Action>) {
    let menu: Vec<Action> = actions_of(obs.legal).collect();
    let lines: Vec<String> = menu
        .iter()
        .enumerate()
        .map(|(i, &a)| format!("{i}) {}", action_label(a, obs)))
        .collect();
    let text = format!(
        "{RULES}\nSituación:\n{}\nJugadas posibles:\n{}\n\nRespondé solo con el número de la jugada.",
        describe(obs),
        lines.join("\n")
    );
    (text, menu)
}

/// El primer número entero de la respuesta, si es una opción del menú.
pub fn parse_choice(text: &str, n: usize) -> Option<usize> {
    let digits: String = text
        .chars()
        .skip_while(|c| !c.is_ascii_digit())
        .take_while(|c| c.is_ascii_digit())
        .collect();
    digits.parse().ok().filter(|&k| k < n)
}

/// La jugada prudente: no querer o tirar la carta más baja (los slots van de la más fuerte a la
/// más débil); si no se puede ninguna, la primera legal.
pub fn fallback(legal: ActionMask) -> Action {
    [NO_QUIERO, JUGAR2, JUGAR1, JUGAR0]
        .into_iter()
        .find(|&a| legal & bit(a) != 0)
        .unwrap_or_else(|| actions_of(legal).next().expect("sin acciones legales"))
}

#[derive(Clone)]
pub struct HaikuOptions {
    pub claude: PathBuf,
    pub model: String,
    pub timeout: Duration,
}

pub struct Answer {
    pub text: String,
    /// Costo a precio de lista que informa Claude Code (con la suscripción no se cobra).
    pub cost_usd: f64,
    /// Nombre completo del modelo que contestó.
    pub model: String,
}

/// Una llamada a `claude -p` con `user` por stdin.
pub fn ask_claude(opts: &HaikuOptions, user: &str) -> Result<Answer, String> {
    let mut child = Command::new(&opts.claude)
        .args([
            "-p",
            "--model",
            opts.model.as_str(),
            "--system-prompt",
            SYSTEM,
            "--tools",
            "",
            "--strict-mcp-config",
            "--setting-sources",
            "",
            "--no-session-persistence",
            "--output-format",
            "json",
        ])
        .current_dir(std::env::temp_dir())
        .stdin(Stdio::piped())
        .stdout(Stdio::piped())
        .stderr(Stdio::null())
        .spawn()
        .map_err(|e| format!("no pude lanzar {}: {e}", opts.claude.display()))?;
    {
        // Al soltar stdin se cierra y Claude empieza a responder.
        let mut stdin = child.stdin.take().expect("stdin de claude");
        stdin.write_all(user.as_bytes()).map_err(|e| format!("claude no recibe: {e}"))?;
    }
    let mut stdout = child.stdout.take().expect("stdout de claude");
    let reader = std::thread::spawn(move || {
        let mut out = String::new();
        let _ = stdout.read_to_string(&mut out);
        out
    });
    let t0 = Instant::now();
    loop {
        match child.try_wait().map_err(|e| e.to_string())? {
            Some(_) => break,
            None if t0.elapsed() > opts.timeout => {
                let _ = child.kill();
                let _ = child.wait();
                return Err(format!("claude no contestó en {} s", opts.timeout.as_secs()));
            }
            None => std::thread::sleep(Duration::from_millis(50)),
        }
    }
    let out = reader.join().expect("lector de claude");
    let v: Value = serde_json::from_str(out.trim()).map_err(|e| format!("salida ilegible de claude: {e}"))?;
    if v["is_error"].as_bool() != Some(false) {
        return Err(format!("claude devolvió un error: {}", v["result"]));
    }
    Ok(Answer {
        text: v["result"].as_str().unwrap_or("").to_string(),

pub struct HaikuAgent {
    opts: HaikuOptions,
    counters: Arc<Counters>,
}

impl HaikuAgent {
    pub fn new(opts: HaikuOptions, counters: Arc<Counters>) -> HaikuAgent {
        HaikuAgent { opts, counters }
    }
}

impl Agent for HaikuAgent {
    fn name(&self) -> String {
        format!("claude-{}", self.opts.model)
    }

    fn act(&mut self, obs: &Observation, _rng: &mut dyn RngCore) -> Action {
        let (text, menu) = prompt(obs);
        if menu.len() == 1 {
            return menu[0];
        }
        self.counters.decisions.fetch_add(1, Ordering::Relaxed);
        for _ in 0..2 {
            match ask_claude(&self.opts, &text) {
                Ok(answer) => {
                    let micro = (answer.cost_usd * 1e6).round() as u64;
                    self.counters.cost_micro_usd.fetch_add(micro, Ordering::Relaxed);
                    if !answer.model.is_empty() {
                        *self.counters.model.lock().expect("modelo") = answer.model;
                    }
                    if let Some(k) = parse_choice(&answer.text, menu.len()) {
                        return menu[k];
                    }
                    eprintln!("haiku: respuesta sin una opción válida: {:?}", answer.text);
                }
                Err(e) => eprintln!("haiku: {e}"),
            }
        }
        self.counters.fallbacks.fetch_add(1, Ordering::Relaxed);
        fallback(obs.legal)
    }
}

```rust
//! Fuerza de una mano para el truco: probabilidad de ganar las bazas contra una mano al azar si
//! los dos tiran cartas con la regla del heurístico y nadie canta. Es una equidad heurística.
use rand::rngs::SmallRng;
use rand::seq::SliceRandom;
use rand::SeedableRng;
use std::collections::HashMap;
use truco_engine::agents::heuristic_card;
use truco_engine::cards::{full_deck, Card};
use truco_engine::truco::TrucoState;

/// "Mano floja" = percentil de fuerza menor que esto.
pub const WEAK: f64 = 0.30;

type Key = [u8; 3];

fn key(hand: [Card; 3]) -> Key {
    let mut k = hand.map(|c| c.id());
    k.sort_unstable();
    k
}

pub struct StrengthTable {
    /// Equidad por mano: [como pie, como mano].
    equity: HashMap<Key, [f64; 2]>,
    /// Equidades ordenadas de las 9880 manos, por rol.
    sorted: [Vec<f64>; 2],
}

/// Gana las bazas la mano `hand` (asiento 0) contra `opp`, tirando cartas con la regla del heurístico.
fn wins(hand: [Card; 3], opp: [Card; 3], is_mano: bool) -> bool {
    let mut s = TrucoState::new_hand([hand, opp], if is_mano { 0 } else { 1 }, [0, 0]);
    while !s.is_over() {
        let p = s.turn();
        s.apply(heuristic_card(&s.observation(p)));
    }
    s.points()[0] > 0
}

fn equity_of(k: Key, is_mano: bool, samples: u32, seed: u64) -> f64 {
    let hand = k.map(Card::from_id);
    let rest: Vec<Card> = full_deck().into_iter().filter(|c| !k.contains(&c.id())).collect();
    let tag = (k[0] as u64) << 16 | (k[1] as u64) << 8 | k[2] as u64;
    let mut rng = SmallRng::seed_from_u64(seed ^ tag.wrapping_mul(0x9E37_79B9) ^ is_mano as u64);
    let won = (0..samples)
        .filter(|_| {
            let opp: Vec<Card> = rest.choose_multiple(&mut rng, 3).copied().collect();
            wins(hand, [opp[0], opp[1], opp[2]], is_mano)
        })
        .count();
    won as f64 / samples as f64
}

impl StrengthTable {
    pub fn build(samples: u32, seed: u64, threads: usize) -> StrengthTable {
        let mut keys = Vec::with_capacity(9880);
        for a in 0..40u8 {
            for b in a + 1..40 {
                for c in b + 1..40 {
                    keys.push([a, b, c]);
                }
            }
        }
        let threads = threads.max(1);
        let parts: Vec<Vec<(Key, [f64; 2])>> = std::thread::scope(|s| {
            let handles: Vec<_> = (0..threads)
                .map(|w| {
                    let keys = &keys;
                    s.spawn(move || {
                        keys.iter()
                            .skip(w)
                            .step_by(threads)
                            .map(|&k| (k, [equity_of(k, false, samples, seed), equity_of(k, true, samples, seed)]))
                            .collect()
                    })
                })
                .collect();
            handles.into_iter().map(|h| h.join().expect("hilo de la tabla de fuerza")).collect()
        });
        let equity: HashMap<Key, [f64; 2]> = parts.into_iter().flatten().collect();
        let sorted = [0, 1].map(|r| {
            let mut v: Vec<f64> = equity.values().map(|e| e[r]).collect();
            v.sort_by(|a, b| a.partial_cmp(b).expect("equidad no numérica"));
            v
        });
        StrengthTable { equity, sorted }
    }

    pub fn equity(&self, hand: [Card; 3], is_mano: bool) -> f64 {
        self.equity[&key(hand)][is_mano as usize]
    }

    /// Fracción de las manos posibles más flojas que esta (los empates cuentan la mitad).
    pub fn percentile(&self, hand: [Card; 3], is_mano: bool) -> f64 {
        let e = self.equity(hand, is_mano);
        let v = &self.sorted[is_mano as usize];
        let below = v.partition_point(|&x| x < e);
        let not_above = v.partition_point(|&x| x <= e);
        (below as f64 + 0.5 * (not_above - below) as f64) / v.len() as f64
    }

    /// Percentil de cada una de las 9880 manos (para tests y gráficos).
    pub fn all_percentiles(&self, is_mano: bool) -> impl Iterator<Item = f64> + '_ {
        self.equity.keys().map(move |k| self.percentile(k.map(Card::from_id), is_mano))
    }
}

}

const ROLES: [&str; 2] = ["pie", "mano"];

fn role_rate(role: &str, accs: &[Acc], invert: bool) -> RoleRate {
    let n: u64 = accs.iter().map(|a| a.n).sum();
    let called: u64 = accs.iter().map(|a| a.called).sum();
    let p: f64 = accs.iter().map(|a| a.p.iter().sum::<f64>()).sum();
    let div = |x: f64| if n == 0 { 0.0 } else { x / n as f64 };
    let rate = div(called as f64);
    RoleRate {
        role: role.to_string(),
        n,
        called,
        rate: if invert && n > 0 { 1.0 - rate } else { rate },
        p_any: div(p),
    }
}

/// Juega `hands` manos de `net` contra sí mismo (o del heurístico, con `None`) y mide el faroleo.
pub fn analyze(
    net: Option<Arc<Mlp>>,
    table: &StrengthTable,
    hands: u64,
    seed: u64,
) -> (Vec<EnvidoPoint>, Vec<RoleRate>, Vec<RoleRate>, TrucoBluff) {
    let mut rng = SmallRng::seed_from_u64(seed);
    let bot = net.map(|n| MlpAgent::shared(n, PolicyKind::Strategy, "bot"));
    let mut heuristic = HeuristicAgent;
    // (rol, tantos) → acumulado
    let mut env: BTreeMap<(usize, u8), Acc> = BTreeMap::new();
    let (mut calls, mut weak_calls, mut folded) = (0u64, 0u64, 0u64);
    for k in 0..hands {
        let scores = sample_scores(&mut rng);
        let mut s = TrucoState::new_hand(deal(&mut rng), (k % 2) as usize, scores);
        let mut had_envido_chance = [false; 2];
        let mut pending_weak_call = false;
        while !s.is_over() {
            let p = s.turn();
            let obs = s.observation(p);
            let probs: Probs = match &bot {
                Some(b) => b.probabilities(&obs),
                None => {
                    let mut one = [0.0; 12];
                    one[heuristic.act(&obs, &mut rng)] = 1.0;
                    one
                }
            };
            let a = sample_action(&probs, obs.legal, &mut rng);
            if pending_weak_call {
                if a == NO_QUIERO {
                    folded += 1;
                }
                pending_weak_call = false;
            }
            let first_envido = obs.legal & bit(ENVIDO) != 0
                && obs.envido_calls.iter().all(|c| c.is_none())
                && !had_envido_chance[p];
            if first_envido {
                had_envido_chance[p] = true;
                let e = env.entry((obs.is_mano as usize, obs.my_tantos)).or_default();
                e.n += 1;
                e.called += matches!(a, ENVIDO | REAL_ENVIDO | FALTA_ENVIDO) as u64;
                e.p[0] += probs[ENVIDO] as f64;
                e.p[1] += probs[REAL_ENVIDO] as f64;
                e.p[2] += probs[FALTA_ENVIDO] as f64;
            }
            if a == TRUCO || a == RETRUCO {
                calls += 1;
                if table.percentile(obs.hand, obs.is_mano) < WEAK {
                    weak_calls += 1;
                    pending_weak_call = true;
                }
            }
            s.apply(a);
        }
    }
    let curve: Vec<EnvidoPoint> = env
        .iter()
        .map(|(&(role, tantos), a)| EnvidoPoint {
            role: ROLES[role].to_string(),
            tantos,
            n: a.n,
            called: a.called,
            p_any: (a.p[0] + a.p[1] + a.p[2]) / a.n as f64,
            p_envido: a.p[0] / a.n as f64,
            p_real: a.p[1] / a.n as f64,
            p_falta: a.p[2] / a.n as f64,
        })
        .collect();
    let rates = |pred: &dyn Fn(u8) -> bool, invert: bool| -> Vec<RoleRate> {
        let pick = |role: Option<usize>| -> Vec<Acc> {
            env.iter()
                .filter(|(&(r, t), _)| pred(t) && role.is_none_or(|x| x == r))
                .map(|(_, a)| *a)
                .collect()
        };
        vec![
            role_rate("mano", &pick(Some(1)), invert),
            role_rate("pie", &pick(Some(0)), invert),
            role_rate("todos", &pick(None), invert),
        ]
    };
    let low = rates(&|t| t <= 7, false);
    let contention = rates(&|t| t >= 31, true);
    let (lo, hi) = wilson(weak_calls, calls);
    let share = |x: u64, n: u64| if n == 0 { 0.0 } else { x as f64 / n as f64 };
    let truco = TrucoBluff {
        calls,
        weak_calls,
        weak_share: share(weak_calls, calls),
        weak_share_wilson95: [lo, hi],
        weak_calls_folded: folded,
        fold_rate: share(folded, weak_calls),
    };
    (curve, low, contention, truco)
}
```

//! Manos destacadas: faroles exitosos del bot en los registros del torneo.
use crate::logs::{HandLog, MatchLog};
use crate::strength::{StrengthTable, WEAK};
use serde::Serialize;
use truco_engine::envido::envido_points;
use truco_engine::truco::*;

#[derive(Serialize, Clone, Debug)]
#[serde(rename_all = "camelCase")]
pub struct Highlight {
    pub rival: String,
    /// "truco" o "envido".
    pub kind: String,
    /// El canto del bot (nombre de ACTION_NAMES).
    pub call: String,
    /// Posición del canto en `hand.actions`.
    pub call_index: usize,
    pub bot_seat: usize,
    /// Truco: percentil de fuerza de la mano (0 = la peor). Envido: los tantos.
    pub strength: f64,
    /// La respuesta del rival: "noQuiero" o "mazo".
    pub response: String,
    pub points_won: u8,
    pub hand: HandLog,
}

#[derive(Serialize, Clone, Debug)]
#[serde(rename_all = "camelCase")]
pub struct HighlightsReport {
    pub sources: Vec<String>,
    pub truco_found: u64,
    pub envido_found: u64,
    pub truco: Vec<Highlight>,
    pub envido: Vec<Highlight>,
}

/// Faroles del bot a los que el rival contestó "no quiero" o "me voy al mazo" (como próxima jugada).
pub fn find(rival: &str, logs: &[MatchLog], table: &StrengthTable) -> Vec<Highlight> {
    let mut out = Vec::new();
    for m in logs {
        let bot = m.bot_seat;
        for h in &m.hands {
            let acts = h.action_ids();
            let cards = h.cards(bot);
            let is_mano = h.mano == bot;
            for (i, &(p, a)) in acts.iter().enumerate() {
                if p != bot {
                    continue;
                }
                let Some(&(q, resp)) = acts.get(i + 1) else { continue };
                if q == bot || !(resp == NO_QUIERO || resp == MAZO) {
                    continue;
                }
                let (kind, strength) = match a {
                    TRUCO | RETRUCO | VALE_CUATRO => ("truco", table.percentile(cards, is_mano)),
                    ENVIDO | REAL_ENVIDO | FALTA_ENVIDO => ("envido", envido_points(&cards) as f64),
                    _ => continue,
                };
                let weak = if kind == "truco" { strength < WEAK } else { strength <= 7.0 };
                if !weak {
                    continue;
                }
                out.push(Highlight {
                    rival: rival.to_string(),
                    kind: kind.to_string(),
                    call: ACTION_NAMES[a].to_string(),
                    call_index: i,
                    bot_seat: bot,
                    strength,
                    response: ACTION_NAMES[resp].to_string(),
                    points_won: h.points[bot],
                    hand: h.clone(),
                });
            }
        }
    }
    out
}

/// Las más flojas primero (y, a igual fuerza, las que dieron más puntos).
pub fn select(found: Vec<Highlight>, top_truco: usize, top_envido: usize) -> (Vec<Highlight>, Vec<Highlight>) {
    let pick = |kind: &str, top: usize| {
        let mut v: Vec<Highlight> = found.iter().filter(|h| h.kind == kind).cloned().collect();
        v.sort_by(|a, b| {
            a.strength
                .partial_cmp(&b.strength)
                .expect("fuerza no numérica")
                .then(b.points_won.cmp(&a.points_won))
        });
        v.truncate(top);
        v
    };
    (pick("truco", top_truco), pick("envido", top_envido))
}
